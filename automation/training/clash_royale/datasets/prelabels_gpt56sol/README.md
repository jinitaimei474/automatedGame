# GPT-5.6 Sol 预标注复核包

本目录包含当前皇室战争图像库的 681 张预标注，供人工复核后再拆分为正式 YOLO 训练集。它不是最终真值。

- `images/`：681 张复核图片。为避免重复占用空间，本机上优先使用原图的硬链接。
- `labels/`：681 个同名 YOLO 标签文件；其中 18 张只有候选说明，标签文件暂为空。
- `annotations.jsonl`：每张图片的像素框、YOLO 框、预标置信度、依据、候选类别和复核原因。
- `review_queue.csv`：人工审核工作队列，包含优先级及待填写的状态、审核人和备注。
- `image_map.csv`：复核文件名与原始图片绝对路径的映射。
- `classes.txt`：34 类的固定顺序。
- `dataset_review.yaml`：用于浏览或验证预标注的 YOLO 配置。
- `summary.json`：图片、框、类别、候选和优先级统计。
- `previews/`：代表性预标框渲染，用于快速检查规则。

当前草稿共有 824 个 YOLO 框：663 张至少有一个框，18 张因加载页、卡组页或卡牌详情等不属于现有可靠类别，只保留了候选说明。所有 681 张在 `review_queue.csv` 中均为 `pending`。

详细人工复核规范见项目文档 `docs/ANNOTATION_REVIEW.zh-CN.md`。
