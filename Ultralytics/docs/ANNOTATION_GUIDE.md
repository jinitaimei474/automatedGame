# YOLO 目标检测标注规范

## 标签格式

每张图片对应一个同名 `.txt` 文件，每个目标占一行：

```text
class_id x_center y_center width height
```

坐标和宽高必须除以图片尺寸，归一化到 `0～1`。例如：

```text
0 0.500000 0.500000 0.250000 0.400000
```

类别 ID 来自根目录 `classes.txt`，第一行是 0，第二行是 1。不要手工改变已经用于训练的类别顺序。

## 边界框原则

- 框紧贴完整可见目标，不包含大量背景。
- 同类目标全部标注，不能只标容易识别的目标。
- 严重遮挡且无法判断类别的目标不标；仍能明确判断时框可见区域或按团队统一规范框完整推测区域，不能混用两种规则。
- 小目标、边缘目标、截断目标需要覆盖，但必须保持规则一致。
- 没有任何目标的图片可作为负样本，标签文件保持为空。
- 不要标注水印、反光或目标影子，除非它们本身就是定义的类别。

## 数据采集与划分

- 覆盖不同分辨率、距离、角度、光照、遮挡、背景、设备和时间段。
- 保留一部分困难负样本，降低误检。
- 视频抽帧按“视频/场景”分组后再划分；禁止把相邻帧随机分到训练集和验证集。
- 同一原图的数据增强版本必须留在同一集合。
- 推荐初始比例 `80%/10%/10%`，小数据集至少确保验证集每类有足够样本。

推荐使用 CVAT、Label Studio 或 Roboflow，导出格式选择 `YOLO` / `Ultralytics YOLO`。
